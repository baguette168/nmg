# NMG P1 (MVP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a CLI tool that generates parameterized .NET memory shell payloads (Godzilla C# protocol, VPP type) output as aspx injector page or Base64.

**Architecture:** Source templates with `{{placeholder}}` syntax → Roslyn compilation to DLL (multi-target net40/net472/net20) → output formatter wraps DLL into aspx injector page or raw Base64. Randomizer controls class/namespace/path naming with optional seed for deterministic output.

**Tech Stack:** C# / .NET 8 (CLI tool), Microsoft.CodeAnalysis.CSharp (Roslyn), Microsoft.NETFramework.ReferenceAssemblies (multi-target compilation), System.CommandLine (CLI parsing).

**Spec:** `需求方案.md` (P1 requirements FR-1.1 through FR-1.8)

## Global Constraints

- Tool itself: .NET 8, single-file self-contained publish (NFR-6)
- Payload templates: C# 2.0-compatible syntax only (NFR-4)
- All payload execution paths wrapped in try-catch, any exception silently passes request through (NFR-1)
- Injection is idempotent: check-before-register (NFR-2)
- No new files in web directory after injection completes (NFR-3)
- Same parameters + fixed seed = identical output (NFR-5)
- Core logic (protocol encode/decode, template rendering) separated from file/compile IO (NFR-7)
- No dynamic compilation on target (avoid `ASP.xxx_aspx+ClassName` scanner signature)

## Review Focus

1. Godzilla protocol key derivation must match Godzilla 4.x client exactly (MD5(pass+key).Substring(0,16) = AES key)
2. Roslyn compilation targeting net40/net20 requires correct reference assemblies
3. VPP static constructor + reflection to RegisterVirtualPathProviderInternal is the only proven registration path
4. aspx injector page must not trigger dynamic compilation of payload code itself (Assembly.Load from byte[])
5. Deterministic output with fixed seed - all random values must derive from the seeded RNG
